## Your Task

1. 会話全体（直近の話題だけでなく、セッションの本題）を踏まえて、日本語のセッション名を1つ決める。
   - 20文字前後、体言止め（例: `dev pull時のローカル差分整理`、`点検フォームのQR遷移修正`）
   - 文にしない。シングルクォート `'` は使わない
2. 次のコマンドでクリップボードにコピーする:

   ```bash
   printf '%s' '/rename <名前>' | pbcopy
   ```

3. 決めた名前だけを返す。説明や案内は付けない。
